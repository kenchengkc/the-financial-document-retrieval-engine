# FDRE documentation

Active documentation is grouped by purpose so operational history does not obscure the current
system contract.

- [`architecture/`](architecture/) — system architecture and feature-lineage contracts.
- [`evaluations/`](evaluations/) — evaluation methodology and measured results.
- [`research/`](research/) — research archive and Historical Universe specifications.
- [`roadmap.md`](roadmap.md) — current delivery roadmap and milestones.
- [`archive/`](archive/) — superseded or historical project records retained for provenance.

When adding documentation, prefer the narrowest existing category. Keep the repository root for
project-level entry points such as `README.md`, not subsystem design notes.
